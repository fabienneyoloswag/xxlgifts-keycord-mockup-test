# XXLGifts Mockup Engine v1

De eerste echte laag-gebaseerde 20 mm keycordgenerator.

## Gebruikte PSD-assets
- base
- color mask
- design mask
- overlay
- shadow
- Duimhaak
- Ovaalhaak
- Karabijnhaak
- Cliphaak luxe
- Krokodil
- Sleutelring

## Functies
- SVG/PNG-logo uploaden
- Keycordkleur kiezen
- Logoformaat, afstand en rotatie aanpassen
- Echte haaklaag kiezen
- Live preview
- PNG downloaden

Alle assets zijn op hetzelfde canvas en dezelfde positie gehouden.
