# XXLGifts echte PSD mockup proof of concept

Deze versie gebruikt `mockup-base.png`, rechtstreeks gerenderd uit de aangeleverde 20 mm PSD.

## Dit werkt
- echte PSD-compositie als productbasis
- keycordkleur wijzigen met behoud van licht en schaduw
- SVG/PNG-logo uploaden
- logo binnen het werkelijke lintmasker plaatsen
- PNG downloaden

## Volgende stap
De PSD in Photoshop eenmalig exporteren naar:
- base
- design mask
- shadows/highlights
- iedere haak
- badge reel
- buckle en safety
- background

Daarmee kan de online tool de mockup vrijwel één-op-één reconstrueren zonder Photoshop op de server.
